## API Reference
- [Upsert transaction](https://developers.justt.ai/reference/transactioncontroller_createtransaction.md): Creates or updates a transaction record for additional purchases or activities made by a customer who has an existing chargeback case. This helps provide additional context for dispute resolution.
- [Get chargeback](https://developers.justt.ai/reference/chargebackitemcontroller_getchargeback.md): Retrieving a single chargeback by id
- [Update chargeback](https://developers.justt.ai/reference/chargebackitemcontroller_updatechargeback.md): To see your full request body parameters names please check you data boost page at the hub https://app.justt.ai/datapoints-list
- [Should Justt fight for a given chargeback](https://developers.justt.ai/reference/chargebackitemcontroller_markshouldfight.md): By default, Justt will represent or not represent chargebacks as agreed in your contract. Use this endpoint to override this for a specific chargeback
- [Accept chargeback](https://developers.justt.ai/reference/chargebackitemcontroller_acceptchargeback.md): Accepts a chargeback, indicating you will not dispute it. This action acknowledges the validity of the customer's claim and allows the funds to be returned to them. The chargeback must have an open status and your payment processor must support acceptance. Once accepted, the chargeback cannot be reversed.
- [Get chargebacks by search criteria](https://developers.justt.ai/reference/chargebackcontroller_findall.md): Retrieving a array of chargebacks matching the given criteria
- [Get the status of an accept chargeback](https://developers.justt.ai/reference/chargebackitemcontroller_getacceptchargebackstatus.md): Returns the current status of an accept chargeback for a chargeback. Accept chargeback is an asynchronous process, so this endpoint allows you to check the real-time state of the accept (e.g., in progress, completed, failed).
- [Request to submit evidence for a chargeback](https://developers.justt.ai/reference/evidencecontroller_submitevidence.md): Submits a request to attach evidence to a chargeback. The evidence will be processed asynchronously; the request will return immediately with a submission ID, and the evidence will be submitted in the background, the process will take up to 24 hours to complete, depending on the payment processor.
- [Get the status of a evidence submission](https://developers.justt.ai/reference/evidencecontroller_getevidencesubmissionstatus.md): Returns the current status of an evidence submission for a chargeback. Evidence submission is an asynchronous process, so this endpoint allows you to check the real-time state of the submission (e.g., in progress, completed, failed).
- [Upload a file](https://developers.justt.ai/reference/filescontroller_create.md): Upload a file to the Justt system. Use multipart/form-data with the file in a field named 'file'. Supported file types include documents, images, and other evidence files. For more details, visit https://developers.justt.ai/docs/file-upload-guide
- [Request data subject removal](https://developers.justt.ai/reference/datasubjectscontroller_requestdatasubjectremoval.md): Request to remove personal data from the Justt system in compliance with data protection regulations (GDPR, CCPA). This endpoint initiates the data deletion process for a specified customer.
- [Get merchants](https://developers.justt.ai/reference/merchantscontroller_getmerchants.md): Retrieve a list of merchants with optional filtering and pagination
- [Deactivate merchant](https://developers.justt.ai/reference/merchantscontroller_deactivatemerchant.md): Deactivate a merchant (note: merchant is not removed, only deactivated)
- [Create merchant](https://developers.justt.ai/reference/merchantscontroller_createmerchant.md): Create a new merchant with business profile information
- [Get merchant by ID](https://developers.justt.ai/reference/merchantscontroller_getmerchant.md): Retrieve a single merchant by its UUID
- [Get integrations](https://developers.justt.ai/reference/integrationscontroller_getintegrations.md): Retrieve a list of integrations with optional filtering and pagination
- [Create integration](https://developers.justt.ai/reference/integrationscontroller_createintegration.md): Create a new payment integration
- [Deactivate integration](https://developers.justt.ai/reference/integrationscontroller_deactivateintegration.md): Deactivate an integration (note: integration is not removed, only deactivated)
- [Get integration by ID](https://developers.justt.ai/reference/integrationscontroller_getintegration.md): Retrieve a single integration by its ID
- [Upload raw data in sandbox environment](https://developers.justt.ai/reference/sandboxcontroller_uploadrawdata.md): This endpoint allows you to upload raw transaction/chargeback data in the sandbox environment for testing purposes. The data will be processed asynchronously and stored in the system.
- [Chargeback Created webhook](https://developers.justt.ai/reference/chargebackcreated.md): Triggered when a new chargeback is received for the merchant.
- [Chargeback Status Updated webhook](https://developers.justt.ai/reference/chargebackstatusupdated.md): Triggered when a chargeback status update is received.
- [Chargeback Updated webhook](https://developers.justt.ai/reference/chargebackupdated.md): Triggered when a chargeback is updated.
- [Chargeback Evidence Submitted webhook](https://developers.justt.ai/reference/chargebackevidencesubmitted.md): Triggered when evidence is successfully submitted to the PSP.
- [Chargeback Accepted webhook](https://developers.justt.ai/reference/chargebackaccepted.md): Triggered when a chargeback acceptance is successfully confirmed by the PSP
- [Pre Chargeback Alert Received webhook](https://developers.justt.ai/reference/pre_chargeback_alertreceived.md): Triggered when a new pre chargeback alert is received from either CDRN, RDR or Ethoca.
- [Refund Alert Succeeded webhook](https://developers.justt.ai/reference/pre_chargeback_alertrefundsucceeded.md): Triggered when the linked transaction to a refunded alert was successfully refunded through the PSP
- [Refund Alert Failed webhook](https://developers.justt.ai/reference/pre_chargeback_alertrefundfailed.md): Triggered when a refund alert is failed to be processed
- [Alert Transaction Matched webhook](https://developers.justt.ai/reference/pre_chargeback_alerttransaction_matched.md): Triggered when an inbound pre-chargeback alert was successfully matched to an underlying transaction. Opt-in only — gated by the additional_event_types account configuration.
- [Cancel Subscription Success webhook](https://developers.justt.ai/reference/subscriptioncancel_immediatelysuccess.md): Triggered when a CRM subscription was successfully cancelled after a refund (e.g. Chargebee or Recurly).
- [Cancel Subscription Failure webhook](https://developers.justt.ai/reference/subscriptioncancel_immediatelyfailed.md): Triggered when cancelling a CRM subscription failed after a refund (e.g. subscription not found or already cancelled).
- [Get alerts by search criteria](https://developers.justt.ai/reference/alertcontroller_findall.md): Retrieving an array of pre-chargeback alerts matching the given criteria. In addition to this endpoint, we also support push notifications that share alerts with you in real-time. Contact your account manager to set up for immediate alert notifications.
- [Get alert](https://developers.justt.ai/reference/alertcontroller_findone.md): Retrieving a single pre-chargeback alert by id
- [Create alert outcome](https://developers.justt.ai/reference/prechargebackalertscontroller_createoutcome.md): Create and record the outcome of a pre-chargeback alert (e.g., refunded, resolved, accepted). Pre-chargeback alerts are early warnings that allow merchants to take action before a chargeback is filed.
